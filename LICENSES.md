Fedorium Linux is made of three kinds of material, each under its own terms.

| What | Files | License |
|---|---|---|
| Scripts, kickstart, spec, configuration | everything not listed below | [MIT](LICENSE) |
| Artwork: wallpapers, logo files, boot splash, fastfetch logo | `branding/files/*.svg`, `branding/files/*.png`, `branding/files/fastfetch-logo.txt` | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| The **Fedorium** name and logo as identifiers | — | see [TRADEMARKS.md](TRADEMARKS.md) |

The artwork license lets you share and adapt the images. The trademark policy is
separate: it only covers using the name and logo to identify a project.

## Third-party software

The Fedorium ISO is assembled from unmodified packages from the Fedora Project
repositories (and, after first boot, RPM Fusion, Flathub and Microsoft's VS Code
repository when the user picks a profile). Each of those packages keeps its own
license. Source code for every Fedora package is available from the Fedora
Project at https://src.fedoraproject.org/ and as source RPMs in the Fedora
repositories.

Fedorium is not affiliated with or endorsed by the Fedora Project or Red Hat.
"Fedora" is a trademark of Red Hat, Inc.; the Fedora logos are not used or
shipped in Fedorium (they are replaced by `generic-logos`).
